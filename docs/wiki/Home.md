# Grid Overview

**See Hyprland, then shape it.** `gridoverview` shows your workspaces, windows and scratchpads as one grid you can grab with the mouse. Nothing has to be configured first; every feature works out of the box and can be refined later.

Workspace ids follow `row * 10 + column` (11–19, 21–29, …). The grid grows as you need it: every row gets an empty workspace past its last used one, and below the last used row there is an empty row, so a window can always be dropped somewhere new.
